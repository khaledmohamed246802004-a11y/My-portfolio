Lecture-by-Lecture Plan

CSD341 Software Engineering — topics and suggested learning activities from the supplied lecture set
Lecture Learning Activities Core Concepts Suggested Preparation
Lecture Focus Applied Focus
Lecture 1 Introduction to Software Engineering Explain what software engineering covers and why a disciplined approach is needed. Software, generic and customized products, software engineering, and the course objectives. Review the course objectives and product examples.
Software quality attributes Identify maintainability, efficiency, correctness, reusability, portability, reliability, and availability in examples. Essential attributes of good software and their importance. Prepare one example for two quality attributes.
Lecture 2 Application Types Classify stand-alone, transaction-based, embedded, data collection, batch, entertainment, and simulation systems. Different software systems require different engineering techniques. Review the application type examples.
Software Engineering Challenges and Ethics Discuss quality, complexity, changing technology, user expectations, and professional responsibility. Confidentiality, competence, intellectual property, and computer misuse. Prepare a short example of an ethical issue.
Lecture 3 Software Processes Arrange specification, design and implementation, validation, and evolution in a process sequence. A software process is a structured set of activities required to develop a system. Review the four recurring process activities.
Plan-Driven, Agile, and Hybrid Processes Choose an approach for a project scenario and justify the choice. Up-front planning, incremental planning, flexibility, and a combination of approaches. Compare a regulated system with a product that changes through user feedback.
Lecture 4 Generic Process Activities and Process Flows Identify linear, iterative, evolutionary, and parallel process flows. Communication, planning, modeling, construction, and deployment. Review the process-flow examples from the lecture.
Software Process Models Match Waterfall, V-Model, Incremental, Spiral, and Reuse-Oriented models to scenarios. Sequential development, linked testing, increments, risk analysis, and component reuse. Prepare one advantage and one limitation of a process model.
Lecture 5 Agile Methodologies and Extreme Programming Explain iterative and incremental delivery and identify XP practices. Small releases, simple design, test-first development, refactoring, pair programming, collective ownership, and continuous integration. Review the XP principles and examples.
Kanban and Scrum Overview Read a basic Kanban board and explain how work moves through it. Visualize work, WIP limits, manage flow, continuous improvement, and Scrum sprints. Describe how a task moves from To Do to In Progress to Done.
Lecture 6 Scrum Roles, Artifacts, and Sprint Cycle Map the Product Owner, Scrum Master, Development Team, and Scrum artifacts to a team example. Product Backlog, Sprint Backlog, Increment, sprint planning, and project closure. Review the sprint cycle and Scrum board.
Agile Tools and Requirements Introduction Compare Jira, Azure DevOps, and Trello; identify stakeholders and system requirements. Agile workflow tools; user needs; functional and non-functional requirements. Prepare one example requirement and one reason to choose an Agile tool.
Lecture 7 Requirements Engineering Process Classify sample statements as functional or non-functional requirements. System and user requirements, stakeholders, constraints, and requirements engineering. Review the definitions and examples of both requirement types.
Requirements Elicitation, Specification, and Validation Write and check a short user story. Interviews, brainstorming, observation, documentation, validity, consistency, completeness, realism, and verifiability. Prepare one clear user story with an actor, goal, and benefit.
