# Project 1 — Documentation

This folder contains the planning documents and evidence for the Accessible Course Mini-Site.

## Evidence status
- The landmark maps and heading outlines describe the implemented HTML structure.
- The user reported that all four HTML pages passed the Nu HTML Checker with no errors or warnings.
- The user confirmed that all 21 form test cases passed in both Google Chrome and Safari.
- Keyboard navigation, visible focus, reverse navigation, and skip-link behaviour were confirmed as passing across all four pages in Chrome and Safari.
- macOS VoiceOver content navigation was confirmed as passing on all four pages in Safari. Heading navigation passed, and the user confirmed that the Rotor opened.
- Contrast ratios were calculated from CSS colour values; one insufficient-contrast combination was corrected. See `contrast-checks.md`.
- The user confirmed that after submitting fictional form data, the GET query string with `name=value` pairs appeared in the address bar. Exact values were not transcribed. See `network-name-value.md`.
- The 300–400-word reflection is complete in `reflection.md`.

## Files
1. `landmark-maps.md` — page landmarks and named regions.
2. `heading-outlines.md` — heading hierarchy on all four pages.
3. `form-field-plan.md` — controls, names, validation attributes, and reasons.
4. `html-validation.md` — validator evidence for all four HTML pages.
5. `network-name-value.md` — submitted form data and GET query-string explanation.
6. `form-test-cases.md` — 21 form test cases across empty, boundary, and invalid values in two browsers.
7. `keyboard-and-screen-reader.md` — keyboard, skip-link, VoiceOver, heading, and Rotor results.
8. `contrast-checks.md` — measured contrast ratios and WCAG AA verdicts.
9. `reflection.md` — final project reflection (300–400 words).
