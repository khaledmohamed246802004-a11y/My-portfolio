Form Guidance

Enter your name and email, choose a preferred date and time, and select one session type. The attendee count, topic interests, and project URL are optional.

This form uses GET so the submitted name=value pairs can be inspected in the URL during testing. Do not enter confidential or sensitive information.

Data and Submission Method

This example collects only contact details and preferences needed to demonstrate a workshop request. It deliberately does not ask for a password, phone number, date of birth, student number, or other unnecessary personal data.

The form uses method="get" for a classroom demonstration. GET places submitted values in the URL, so this example must not be used for confidential information or as a real registration service.
